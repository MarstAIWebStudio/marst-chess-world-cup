# MARST Chess World Cup ♟️

실시간 온라인 체스 월드컵 프로젝트.

## Features

- 닉네임 기반 참가 신청
- 랜덤 대진표 생성
- 3판 2선승제 경기
- 체스판과 기보
- Stockfish 분석 패널
- 9종 수 평가 기호
- 관중 모드
- Firebase 연동 준비
- 반응형 UI

## Tech Stack

- React
- TypeScript
- Vite
- chess.js
- Stockfish
- Firebase
